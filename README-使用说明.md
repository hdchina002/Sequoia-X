# Sequoia-X 使用说明（本地 + 云端双通道）

仓库：https://github.com/hdchina002/Sequoia-X （public）
Actions：https://github.com/hdchina002/Sequoia-X/actions

---

## 一、它是怎么跑的

```
每日 17:40 起（北京时间，每 20 分钟一次，共 8 次）
        ↓
GitHub Actions 容器启动（Ubuntu，临时，跑完销毁）
        ↓
从缓存恢复 SQLite（约 256MB，400 个交易日 × 5224 只）
        ↓
[探针] 今天有数据吗？没数据（休市/未发布）→ 直接退出
        ↓
[增量] 3 进程并行，每只票只补最近几天的 K 线
        ↓
7 个策略跑一遍 → 有结果的推飞书卡片
        ↓
滚动裁剪（只留最近 400 交易日）→ 保存回缓存
        ↓
写入"今天已完成"标记；后续 7 次 cron 读到标记直接退出
```

**为什么挂 8 条 cron**：GitHub 的定时任务是"尽力而为"，高峰期常延迟 10~40 分钟，
偶尔整条跳过。挂 8 条 + 幂等标记，效果就是你要的"没跑成就 20 分钟后再来一次，
跑成了绝不重复发群消息"。

## 二、日常你只需要看两个地方

| 想看什么 | 去哪 |
|---|---|
| 今天推没推成功 | Actions 页面，看最近一次运行是不是绿勾 |
| 群里收到卡片没有 | 飞书群（每天 17:40~20:00 之间，有票才推） |

**注意**：某个策略当天没选出票，不会推空消息——所以"群里安静"不等于"没跑"，
以 Actions 的绿勾为准。

## 三、想手动跑一次

Actions 页面 → 左侧「Sequoia-X 每日选股」→ 右上「Run workflow」→ 选分支 main
→ 要不要勾 `force`：

- **不勾**：如果今天已经推过了，立刻退出（安全，不会刷屏）
- **勾上 force**：忽略"今天已完成"判定，强制再跑一遍并**重复推送**（调试用）

## 四、常改的几个参数

全部在 `.github/workflows/sequoia-daily.yml`：

| 参数 | 位置 | 说明 |
|---|---|---|
| 跑的时间 | `cron:` 8 行 | GitHub 只认 **UTC**，北京时间 = UTC+8。北京 17:40 = `40 9 * * 1-5` |
| 保留多少天 | `KEEP_DAYS: '400'` | 每多 100 日约 +64MB 缓存。RPS 策略至少要 250 日 |
| 并发数 | `daily_run.py` 里的 `--workers 3` | **不要调高**，8 并发会触发 baostock 黑名单 |
| 飞书地址 | 仓库 Settings → Secrets → `FEISHU_WEBHOOK_URL` | 换群就改这里，代码不用动 |

改完直接提交到 main 即生效（`push` 不会触发选股，只改配置是安全的）。

## 五、出问题怎么查

**① 群里没收到，Actions 是红叉**
点进去看哪一步红的。最常见是 `执行每日选股` 报 `黑名单用户` —— 说明 runner 的 IP
被 baostock 临时封了（Azure 共享 IP 偶发）。不用管，下一轮 cron 会自动重试；
连续多天都这样再考虑换数据源。

**② 报 `FileNotFoundError: logs/failures.log`**
说明 `logs/` 目录没建。代码里已加自动创建，若再出现说明 checkout 到了旧提交。

**③ 运行时间突然变成快 1 小时**
说明缓存的库丢了（GitHub 7 天未访问会清缓存，或长假连着没跑），触发了首次回填。
回填完就恢复正常速度，不用干预。

**④ 定时任务突然不跑了**
GitHub 规定：仓库连续 **60 天没有任何提交活动**，会自动停用 schedule。
随便提交一次（哪怕改个空格）就能恢复。

**⑤ 想换群 / 换机器人**
Settings → Secrets and variables → Actions → 更新 `FEISHU_WEBHOOK_URL`。
⚠️ 飞书机器人安全设置里**不要勾"签名校验"**（本项目不发 timestamp/sign，勾了必报 19021），
要防护就勾"自定义关键词"，填 `选股`。

## 六、额度账（GitHub 免费版）

| 项目 | 额度 | 我们实际 |
|---|---|---|
| Actions 分钟 | public 仓库**完全不限、免费** | 每天约 5 分钟（首次回填约 60~90 分钟） |
| 缓存容量 | 10 GB / 仓库，7 天未访问自动清 | 每天只写 1 份 256MB，月均约 5.6GB |
| 仓库单文件 | 100 MB | 数据库**不进 git**，只走缓存 |

超出缓存上限不会扣钱，GitHub 按"最久未访问"自动淘汰旧缓存。

## 七、本地这套还留着干什么

本地 `data/sequoia_v2.db` 只回填了 929 只（600/601 段），且本机 IP 曾被 baostock 封禁。
**正式数据以云端为准**，本地仅用于：

- `预览选股结果-双击我.bat`：跑策略但不推送，终端看结果（调试用）
- `跑一次选股-双击我.bat`：手动跑一次含推送（本机 IP 解封后可用）
- 改代码后先在本地验证语法与策略逻辑，再推云端
